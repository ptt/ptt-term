# ptt-term

The HTML5 based web client for connecting to an ANSI terminal based BBS site.
This is the source of the web hosted on [term.ptt.cc](https://term.ptt.cc/) and [term.ptt2.cc](https://term.ptt2.cc/) .

## History
The `ptt-term` is forked from [robertabcd/PttChrome](https://github.com/robertabcd/PttChrome), which was
derived from [iamchucky/PttChrome](https://github.com/iamchucky/PttChrome).

The original `PttChrome` was a pure Chrome extension.
`robertabcd` added websocket and ported it to be a pure HTML5 website that does not depend on Chrome anymore and that
became the code running behind `term.ptt.cc` until 2026.

`robertabcd` has stopped the development since 2022, and an active branch for other BBS (i.e., [DreamBBS](term.ccns.ncku.edu.tw))
can be found on [ccns/PttChrome](https://github.com/ccns/PttChrome/), maintained by [IepIweidieng](https://github.com/IepIweidieng).

`ptt-term` is the official repo for the `term.ptt.cc` and will collect patches from other active PttChrome forks, with its own patches.
